デジタル音響証拠記録と技術精度規範

SOUNDTEST.PRO は、ブラウザネイティブの Web Audio API による高精度デジタル信号処理を活用し、騒音被害現場における客観的かつ耐タンパー性に優れた音響証拠を生成します。IEC 61672-1 / JIS C 1509-1 に準拠した高精度アルゴリズムにより、管理会社への相談や民事調停に耐えうる決定的な証拠基盤を提供します。

高度な音響解析機能

コア技術仕様

A特性・C特性・Z特性のリアルタイム周波数補正フィルタ、Fast（125ms）/ Slow（1000ms）動特性、等価騒音レベル（LAeq）、統計騒音レベル（L5/L10/L50/L90/L95）、1/3オクターブバンド解析、ミリ秒刻印とGPS透かし付きレポート出力に対応。

専門的な証拠化ワークフロー

現場事実のデジタル固定

マンションの上階足音、飲食店重低音、工事騒音などの現場事実をリアルタイムにデジタル固定。タイムスタンプ、周波数スペクトル、現場写真を不可逆・改ざん防止形式で結合し、調停や交渉における反論の余地のない事実証拠を構成します。

ハードウェア補正と高信頼性

実測ベースの誤差制御

各種スマートフォンおよびPCのMEMSマイク特性に対応。高精度騒音計および94dB音学校正器による実測データをもとに感度特性を補正し、標準的な日常環境下で±1〜2dBの安定した測定精度を維持します。手動での校正オフセット調整にも対応しています。

証拠能力を高める測定手順

高信頼度データ収集プロトコル

  • 測定位置の固定：マイクを床上1.2〜1.5mの高さに保ち、壁や家具からの音響反射を避けて設置します。
  • 環境背景の記録：測定時の窓やドアの開閉状況、空調の作動状態などの環境条件を正確に記録します。
  • 複数日にわたる追跡：単発の騒音だけでなく、7〜14日間の継続的な発生パターンとピーク値を蓄積します。
  • 証拠パッケージの保存：生データCSV、波形スペクトル、透かし写真、PDF報告書を一式で保管し完全性を担保します。
暗号化検証：出力されるSHA-256暗号化ハッシュにより、生成された報告書やデータの改ざんがないことが数学的に証明され、民事調停や交渉における強力な客観的証拠（疎明資料）として活用できます。
