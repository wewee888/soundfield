デジタル音響証拠記録と技術精度規範

SOUNDTEST.PRO は、ブラウザネイティブの Web Audio API による高精度デジタル信号処理を活用し、騒音被害現場における客観的かつ耐タンパー性に優れた音響証拠を生成します。IEC 61672-1 / JIS C 1509-1 に準拠した高精度アルゴリズムにより、管理会社への相談や民事調停に耐えうる決定的な証拠基盤を提供します。

高度な音響解析機能

コア技術仕様

A特性・C特性・Z特性のリアルタイム周波数補正フィルタ、Fast（125ms）/ Slow（1000ms）動特性、等価騒音レベル（LAeq）、統計騒音レベル（L5/L10/L50/L90/L95）、1/3オクターブバンド解析、ミリ秒刻印とGPS透かし付きレポート出力に対応。

専門的な証拠化ワークフロー

現場事実のデジタル固定

マンションの上階足音、飲食店重低音、工事騒音などの現場事実をリアルタイムにデジタル固定。タイムスタンプ、周波数スペクトル、現場写真を不可逆・改ざん防止形式で結合し、調停や交渉における反論の余地のない事実証拠を構成します。

ハードウェア補正と高信頼性

実測ベースの誤差制御

各種スマートフォンおよびPCのMEMSマイク特性に対応。高精度騒音計および94dB音学校正器による実測データをもとに感度特性を補正し、標準的な日常環境下で±1〜2dBの安定した測定精度を維持します。手動での校正オフセット調整にも対応しています。

証拠能力を高める測定手順

高信頼度データ収集プロトコル

  • 測定位置の固定：マイクを床上1.2〜1.5mの高さに保ち、壁や家具からの音響反射を避けて設置します。
  • 環境背景の記録：測定時の窓やドアの開閉状況、空調の作動状態などの環境条件を正確に記録します。
  • 複数日にわたる追跡：単発の騒音だけでなく、7〜14日間の継続的な発生パターンとピーク値を蓄積します。
  • 証拠パッケージの保存：生データCSV、波形スペクトル、透かし写真、PDF報告書を一式で保管し完全性を担保します。
暗号化検証：出力されるSHA-256暗号化ハッシュにより、生成された報告書やデータの改ざんがないことが数学的に証明され、民事調停や交渉における強力な客観的証拠（疎明資料）として活用できます。
数値の意味

ブラウザの騒音計がデシベルを推定する仕組みと、証明できないこと

SOUNDTEST.PRO は Web Audio API でマイクを読み、IEC 61672-1 を模したデジタルの A/C/Z 特性をかけ、保存済みの端末オフセットを足します。結果は時系列のための現場推定値です。校正された騒音計の指示値ではありません。

信号の通り道

ブラウザは振動板の生の電圧を受け取りません。OS とブラウザは、制約を切らない限り、ゲイン、自動ゲイン、ノイズ抑制、エコーキャンセルをまだかけることがあります。ケース、指、風、画面を下にした置き方は、フィルタの前にレベルを変えます。同じ部屋の 2 台の電話は、ツールがどちらも設計どおり動いていても、画面の許容差より大きくずれることがあります。

±1〜5 dB が当てはまる条件

製品に入っている端末プロファイルは、一般的な電話で基準騒音計と 94 dB の音響校正器に合わせたものです。この幅は、音声帯域の音、塞がれていないマイク開口、その端末に合うプロファイルが前提です。壁越しの低音、音声帯域より上のサイレン、覆われたマイク、プロファイルのないノート PC は外に出ることがあります。差が大きいときは校正オフセットを保存する理由であり、2 台を平均して公式値と呼ぶ理由ではありません。

SHA-256 の行が証明すること

マニフェストのハッシュは、書き出したファイルのバイト列に対して計算します。CSV や PDF を書き換えるとハッシュは一致しません。マイクが正確だったこと、GPS が正しい建物を指したこと、メモが出来事を書いていることは証明しません。向きが悪くても改変されていない録音には、ハッシュが付いたままです。ファイルの完全性と音の事実は別の主張で、書き出しが支えるのは前者だけです。

電話の記録とクラス 1 / クラス 2 の騒音計

IEC 61672-1 のクラス 1 またはクラス 2 の騒音計は、機器全体として検査されます。1 kHz の基準点での許容区間は、クラス 1 で約 ±1.1 dB、クラス 2 で約 ±1.4 dB で、周波数、方向、温度が変わると広がります。ソフトで A 特性の曲線を写しても、電話はどちらのクラスにも入りません。電話の記録は、いつ、どこで、おおよそどれくらい大きかったかを、音声とメモ付きで示すために使います。罰金、契約上の違約、行政の記録がその数値そのものに依存するときは、規則が指定する方法で検定済みの騒音計を使います。

次の測定と比べられるようにする

  • 同じ電話、同じケース、同じ周波数重み付け、同じ Fast または Slow。
  • マイクは床から約 1.2〜1.5 m。ポケットの中や壁に付けない。
  • 窓、ほかの音源、分かるなら距離を書く。時間の長さがないピークは LAeq や 8 時間暴露と比べにくい。
  • 数値を限度値と並べるなら、校正器か信頼できる騒音計でオフセットを決め、書き出しに残す。
  • 音声、CSV、PDF、マニフェストを一緒に保存する。ハッシュが覆うのは、実際にハッシュしたファイルだけです。

WHO、OSHA、地域の規則と突き合わせる前に基準のページの数値を読み、報告書の見本と同じように元ファイルを残してください。メモが揃ってから記録ツールを開きます。記録ツールは適合を判断しません。
