关于 SOUNDTEST.PRO

致力于将专业实验室级声学分析与防伪可信数字存证技术，直接带入普通用户的现代浏览器（提供民间事实自查与调解参考）。

我们的使命

让专业声学取证触手可及

邻里纠纷、施工夜间扰民、商业街区轰鸣……在过去，普通市民要记录突发噪音，要么耗资数千元购买工业声级计，要么面临取证难、对方否认、缺乏时间戳维权被动的窘境。

SOUNDTEST.PRO 由专业声学工程师与软件技术团队创立，旨在利用现代 Web Audio API 与数字信号处理技术，打造免安装、高灵敏、具备防伪防篡改特性的民间声学记录工具，所有数据完全在本地私密运算，保障每位居民的宁静居住权益。

声学技术规范

严格遵循 IEC 61672 声学标准

SOUNDTEST.PRO 的数字滤波算法严格参照国际电工委员会 IEC 61672-1 2级声学仪器标准构建：

  • 真有效值与计权滤波：内置精准 A计权（人耳听觉敏感度）、C计权（低频轰鸣与机械振动）和 Z计权（平直频响）。
  • 动态时间积分：提供 Fast（125ms 快响应）与 Slow（1000ms 慢响应）时间常数，准确抓捕突发声与连续声。
  • 统计声学指标：实时计算等效连续声级 LAeq，以及国际公认的 L10、L50、L90 累积百分数声级。
  • 防篡改数字指纹：采用 SHA-256 加密散列算法封存时序读数与 GPS 坐标，形成经得起各方查验的客观记录闭环（民用调解参考，非法定强制计量认证）。
