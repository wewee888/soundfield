本地优先，守护高度敏感的声学取证隐私

噪声取证往往包含人声交谈、私人起居空间、精确家庭住址及邻里纠纷细节。SOUNDTEST.PRO 坚持在您的设备本地处理所有音频频谱与证据，绝不擅自上传云端，确保取证过程安全私密。

麦克风

设备端本地实时计算

麦克风音频流仅在浏览器本地 Web Audio API 管道内计算实时分贝与 FFT 频谱。仅在您明确点击“录音/录像”后才会创建本地临时媒体切片。

摄像头

仅在取证时主动调用

仅用于声学快照叠加分贝水印或现场视频录像。用户可完全自主控制何时开启画面或生成媒体，绝无后台偷录。

位置标注

自主选择精度级别

用于在报告中标注 GPS 经纬度、城市区划及取证时间戳。逆地理编码仅向公开地图接口请求必要地名，不留存轨迹。

本地存储

localStorage + IndexedDB

测量参数与文字记录保存在 localStorage，音视频证据保存在本地 IndexedDB 数据库中，完全受浏览器沙盒隔离保护。

证据导出

由您全权决定分发

生成的 PDF 维权报告、CSV 数据表、音视频原文件与 JSON 摘要清单均由您主动点击下载保存至设备本地。

零云端留存

保护公民隐私不泄露

不设中心化音视频服务器，不存在服务器端泄露或被第三方截获您的家庭隐私录音之风险，数据自主可控。

法律与取证提示

请在合法合规框架内规范取证

  • 严格遵守中国《民法典》第一千零三十二条关于隐私权的规定，取证应限于自身专有住宅或公共受扰空间。
  • 避免在未经同意的情况下拍摄他人面部、私人居所内部或扩散包含他人非公开言论的敏感录音。
  • 浏览器缓存可能随系统清理而失效，请在每次重要取证完成后及时导出 PDF 与音视频文件妥善本地备份。
我们的隐私承诺：少采集、全本地、不监控、明确提示。让维权者在依法收集受扰证据的同时，彻底免除个人隐私泄露的后顾之忧。
